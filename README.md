# K-뉴딜 교육운영관리를 한눈에

K-뉴딜 아카데미 운영매니저·강사·현장운영진·수강생 4개 역할이 한 화면에서 함께 쓰는 교육운영 통합 서비스 프로토타입입니다.
2026 대한민국 청년 CAREER FAIR AI 해커톤 출품용이며, **모든 데이터는 가상 예시 데이터**입니다(실제 개인정보 없음).

- 실행: https://fhfk-spec.github.io/knewdeal-edu-ops/ (설치·로그인 없이 브라우저에서 바로 실행)
- 구성: 단일 HTML 파일(index.html). 데이터는 접속한 브라우저에만 저장됩니다.
