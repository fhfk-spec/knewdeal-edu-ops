# K-뉴딜 교육운영관리를 한눈에

K-뉴딜 아카데미 운영매니저·강사·현장운영진·수강생 4개 역할이 한 화면에서 함께 쓰는 교육운영 통합 서비스 프로토타입입니다.
2026 대한민국 청년 CAREER FAIR AI 해커톤 출품작(팀 린치핀 · 대표 최혜림)이며, **모든 데이터는 가상 예시 데이터**입니다(실제 개인정보 없음).

- **실행 링크**: https://fhfk-spec.github.io/knewdeal-edu-ops/ (설치·로그인 없이 브라우저에서 바로 실행)
- **사용법**: 접속 → 역할(운영매니저·강사·현장운영진·수강생) 선택 → 입장
- **개발 기간**: 2026-11-19 착수 ~ 2026-11-23 제출 (해커톤 기간 중 전부 개발)

## 1. 개발 구조
```
index.html  (단일 파일 웹앱: HTML + CSS + JavaScript, 서버 없이 작동)
 ├─ 화면 계층     역할별 홈 · 상단 메뉴(홈/운영브리핑/공지사항/서류·행정/학습/자유소통방/학생관리/조직·투표/출결)
 ├─ 데이터 계층   참여자 · 출결 · 공지 · 서류 · 학습 · 문의 · FAQ · 게시판 (브라우저 저장소에 저장)
 ├─ 알림 계층     누가 무엇을 바꾸면 관련 역할에 알림 + 확인 여부 기록
 └─ AI 에이전트 계층
      · AI 운영비서      자연어 요청("오늘 결석자 명단") → 데이터 조회 → 표·엑셀(CSV)
      · FAQ 자동 답변    문의를 등록 FAQ와 맞춰 즉답, 문의 유형 분류·담당자 배정, 못 푼 문의는 매니저에게 이관
      · 출결관리봇       09:00 미입실자 알림 → 응답(가는 중·지각·병결·결석) 분류 → 출석부 반영
      · 강의 정리집·복습퀴즈  생성형 AI(Claude)가 강의 녹취로 정리집 + 퀴즈 5문항 초안 생성 → 강사 확인 후 공개
      · 문의 문장 완성   키워드 입력 → 받는 사람에 맞는 문의 글 작성
```

## 2. 기능 모듈 (소스는 약 20개 모듈을 빌드해 index.html 한 파일로 합침)
| 모듈 | 기능 |
|---|---|
| 핵심·계산 | 역할 로그인, 공용 데이터, 출석률·수당 계산 |
| 운영브리핑 | 오늘 요약 KPI, 위험 수강생, 안내문 초안 |
| 출결 | 출석부(지각·조퇴·외출·공가 규칙), 입실 체크, 출결관리봇 |
| 공지·조직 | 공지 게시판, 운영 조직도(이미지 저장), 투표 |
| FAQ·문의 | FAQ 자동 답변, 문의 분류·배정, 문의 문장 완성 |
| 서류 | 결석·지원금·영수증 서류 분류, 제출 현황·누락자 표시 |
| 학습 | 학습로그, 커리큘럼·자료, 깃허브·제작물 제출, 강의 정리집·복습퀴즈 |
| 생활 | 비플페이 결제 가능 식당 지도, 자유소통방(게시판+단톡), 메모장 |

## 3. AI 오류·한계 대응
- FAQ 자동 답변은 **등록된 FAQ 안에서만** 답하고, 맞는 답이 없으면 지어내지 않고 사람에게 넘김
- 생성형 AI 연결이 없거나 오류가 나면 **규칙 기반 초안으로 자동 대체** (서비스가 멈추지 않음)
- AI 초안(정리집·퀴즈·안내문)은 **사람이 확인한 뒤에만** 공개·발송
- 데이터가 없는 칸은 0과 구분해 '데이터 없음'으로 표시
- 한계: 이 공개 링크에서는 생성형 AI 기능이 규칙 기반 초안으로 동작(생성형 AI는 claude.ai 링크 안에서 동작). 다중 사용자 실시간 공유는 구글 시트·Apps Script 연동으로 확장 예정
